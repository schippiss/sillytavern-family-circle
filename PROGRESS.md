# Этапы разработки

## 1. Основа — готово

Отдельное расширение для GitHub; API проверен по исходникам SillyTavern release. Семья и настройки хранятся в метаданных чата. Отдельная модель не нужна.

## 2. Первая реализация — готово

Карточки и связи, активность, системная инструкция, выбор актуальных карточек, окно из волшебной палочки, плавающие ладони, ручные договорённости и отключаемый автоматический учёт.

## 3. Локальные проверки — пройдены

Восемь автоматических тестов логики. Проверка браузером четырёх размеров экрана × четырёх разделов, сохранения полей, роли system, пропуска quiet, переключения чата, сохранения архива, загрузки в новый чат и независимости копий. Ошибок JavaScript не обнаружено. API браузерного теста имитирует SillyTavern. Скриншоты находятся в соседней рабочей папке `family-circle-preview`, они не нужны для установки.

## Дополнение 0.2.0 — готово

Архив именованных наборов семьи и друзей в настройках аккаунта. Загрузка по выбору пользователя заменяет только состав близких, сохраняя настройки и дела текущего чата. Сохранения не содержат поручений и состояния сцен. Отдельная кнопка добавления друга, тип связи, подсказка о собственной жизни и дополнительная краткая инструкция о дружбе. Переключатель отключения сохраняет все данные и очищает промпт.

## Принятые ограничения первой версии

Нет отдельного анализа сцены, долгосрочной памяти и сканирования лорбуков. Выбор присутствующих по имени дополняется ручным переключателем. Настройки не переносятся между чатами автоматически. Кнопка находится справа внизу; перетаскивания пока нет. Поведение модели нельзя гарантировать одной системной инструкцией. Автоматические договорённости по умолчанию выключены для экономии токенов.
